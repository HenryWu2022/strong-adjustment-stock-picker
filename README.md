## 1. 快速开始

### 一键运行（推荐）

双击 **`启动选股系统.bat`**，自动完成：
1. 安装依赖（baostock）
2. 扫描全A股
3. 打开浏览器展示结果


## 2. 功能说明

- **全A股扫描**：通过 baostock 获取沪深全部 A 股日K线数据，执行强势调整形态筛选
- **多维度评分**：涨停（+2分）、试盘线（+2分）、大阳线（+1分）
- **买点 B 计算**：涨停后第 3 日起，出现阳线上穿 MA5 时触发（此买点仅供参考，详细
- **止损 S 计算**：基于涨停日最低价，风险超过 10% 时自动调整
- **K 线可视化**：蜡烛图 + 成交量 + MA 均线 + 买点/止损标注
- **评分详情表**：展示每只股票的评分明细
- **桌面 GUI**：`stock_picker_gui.pyw` 提供 tkinter 桌面界面，支持排序/详情/导出

## 3. 数据源

**baostock** — 免费开源的 A 股历史行情数据 Python 库，无需注册，无需 API Key。

至于为什么要选择baostock数据源，是因为东方财富多次访问会遭到IP级封禁，无法再次获取任何数据，其他数据源也有访问不稳定等糟糕体验，不过如果你有其他数据源API，当然可以自己接入，更加方便，因为这个baostock数据源是免费开源的，每次只能单线程访问，多线程也会被封禁，导致程序运行时间在三四十分钟，请耐心等待

## 4. 强势调整模型规则

> 某股票出现涨停后，进入缩量横盘整理，价格始终不跌破涨停日最低价，且当前价仍在 20 日均线之上。

**初筛条件（必须全部满足）：**

| # | 条件 | 说明 |
|---|------|------|
| 1 | 近7个交易日内存在涨停日 | 多头强势表态 |
| 2 | 涨停日不能是连板 | 排除连续涨停后的高位震荡 |
| 3 | 涨停后最低价不破涨停日最低价 | 涨停板支撑有效 |
| 4 | 当前收盘价 > MA20 | 中期趋势仍向上 |

---

## 5. 评分规则

评分窗口：**最近 40 个交易日**。优先级：涨停 > 试盘线 > 大阳线。

| 类型 | 判定条件 | 分值 |
|------|----------|------|
| **涨停** | 涨幅达板块涨停阈值，封板 | +2 |
| **试盘线** | 阳线，实体 < 3%，上影线 ≥ 2×实体，放量 | +2 |
| **大阳线** | 阳线，实体涨幅 > 3%（非涨停、非试盘线） | +1 |

---

## 6. 买点 B 规则

1. 以最近一次涨停日为基准
2. 从涨停日后的第 3 个交易日开始寻找
3. 找到第一个满足条件的交易日：阳线 + 涨幅>0 + 收盘价>MA5
   
***4. 此买点规则仅供参考，并非强势调整的买入信号，具体的买入信号，欢迎到抖音B站关注小然拆解账号，里面有具体的买卖点教学视频
---

## 7. 止损 S 规则

- 默认止损价 = 涨停日最低价
- 风险比例 > 10% 时，止损价 = 买入价 × 0.9
